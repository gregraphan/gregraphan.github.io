# Team 79 Krunch — 2026 website

Static website for **FIRST® Robotics Competition Team 79 "Krunch"** (the Interact Club of Krunch Robotics), Tampa Bay, FL — a 2026 visual makeover.

**Live:** https://gregraphan.github.io/

Hand-built static site (HTML/CSS/vanilla JS). Pages are assembled from `content/*.html` partials into shared chrome by a small Node script (`_build/build.mjs`); the built pages, `assets/`, `css/`, and `js/` are served as-is (no build step required to host).
